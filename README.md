# 나의 기록 (MyRecord)

개인 메모, 반복 루틴, 월/연간 목표, 달력, 대시보드와 홈 화면 위젯을 한 곳에서 관리하는 Android 앱입니다.

> 이 저장소는 **공개용으로 개인정보와 사용자 데이터, APK, 서명키를 제거한 소스 코드**입니다.

## v1.8.1 주요 기능

- 날짜별 체크리스트와 자유 메모
- 반복 루틴과 요일별 일정
- 월간/연간 목표
- 메모 검색, 폴더, 태그, 사진 첨부
- **메모 정렬: 마지막 수정순 / 제목순**
- **메모 고정: 고정한 메모는 항상 목록 최상단**
- 고정 메모끼리도 선택한 정렬 기준 적용
- 메모/체크리스트 자동 저장
- 달성률 대시보드와 월간 달력
- 오늘 기록 / 반복 루틴 / 월 목표 / 연 목표 / 최근 메모 / 대시보드 / 달력 위젯
- 네트워크 권한 없이 로컬 저장

## 데이터와 개인정보

앱의 실제 사용자 데이터는 Android 앱 내부 저장공간의 `my_record_data.json` 및 첨부 사진으로 저장되며 **이 저장소에는 포함하지 않습니다.**

공개 저장소에는 다음 항목을 포함하지 않습니다.

- 개인 메모, 루틴, 목표, 체크리스트 데이터
- 첨부 사진
- APK 파일
- 릴리스 서명키 (`.jks`, `.keystore`)
- 서명 비밀번호 및 개인 배포 정보

## 메모 정렬 / 고정

v1.8.1에서 추가된 기능입니다.

- `마지막 수정순`: 최근 수정한 메모부터 표시
- `제목순`: 한글/영문 제목 기준 정렬
- `📌 고정`: 정렬 방식과 무관하게 고정 메모를 최상단에 표시
- 기존 데이터에 `pinned` 값이 없으면 자동으로 `false`로 처리

## 직접 빌드

Android API 34 SDK, Build Tools 34.0.0, JDK 17 환경에서:

```bash
./build.sh
```

이 스크립트는 공개 저장소 안전성을 위해 **서명되지 않은 APK**만 생성합니다.
배포용 APK 서명키는 저장소 밖에서 별도로 관리하세요.

## 기술 정보

- Java
- Android SDK (외부 라이브러리 없음)
- 최소 Android 6.0 (API 23)
- 대상 Android 14 (API 34)
- 로컬 JSON 저장
- Android App Widget
